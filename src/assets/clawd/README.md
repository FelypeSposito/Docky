# Clawd animations

These animated SVGs come unchanged from [clawd-pet](https://github.com/abderrahimghazali/clawd-pet) by Abderrahim
GHAZALI, under the MIT license (copy in `LICENSE` next to this file):

- `clawd-working-thinking.svg`, `clawd-working-building.svg`, `clawd-working-tool-calling.svg`,
  `clawd-working-reviewing.svg`, `clawd-working-juggling.svg`: Claude Code working (thinking, editing, running
  commands, reading, with subagents)
- `clawd-notification.svg`: a session is waiting for your permission
- `clawd-idle-living.svg`: sessions are open but nothing is running
- `clawd-sleeping.svg`: no session
- `clawd-celebrating.svg`: a session just finished (also in the "Claude terminou" pill)
- `clawd-sad.svg`: you just denied a permission
- `clawd-gaming.svg`: the pill notice after a long game
- `clawd-coffee.svg`, `clawd-yoga.svg`: the end of a Foco (short break, long break)
- `clawd-coding.svg`: the end of a break, back to focus
- `clawd-dancing.svg`, `clawd-music.svg`: with the eyes off, Clawd in their place when Claude Code is idle (dancing with
  no music, listening along while music plays)

Clawd, the Claude Code mascot, is a character of Anthropic. Docky is an unofficial, non-commercial project and is not
affiliated with or endorsed by Anthropic.
